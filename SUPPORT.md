# Support

Use [GitHub Discussions](https://github.com/fleetbase/fleetbase-php/discussions) for SDK usage questions and [GitHub Issues](https://github.com/fleetbase/fleetbase-php/issues) for reproducible defects or documentation gaps.

Before opening an issue, confirm it reproduces on the latest release and include the SDK, PHP, Composer, framework, and Fleetbase API versions. Provide a minimal sanitized example and the expected and actual behavior. Never include API keys, authorization headers, customer data, or production payloads.

Fleetbase product and commercial support options are available at [fleetbase.io](https://fleetbase.io). Security reports must follow [SECURITY.md](SECURITY.md).
